[main.html의 single-file 폼 (uploads 폴더가 없는 상태에서 시작)]
실행 환경: Spring Boot 4.1.2 내장 Tomcat, http://localhost:8080
요청은 브라우저 대신 스크립트로 보냈다. > 는 보낸 요청, < 는 받은 응답이다. HTML 본문은 <body> 안쪽만(주석 제외) 옮겼다.
============================================================

--- 1) a.PNG 업로드 (uploads 폴더 파일 0 → 1개) ---
> POST /single-file
> Content-Type: multipart/form-data → description=첫 번째 이미지 | singleFile=a.PNG (image/png, 185 bytes)

< HTTP/1.1 200
< Content-Type: text/html;charset=UTF-8
