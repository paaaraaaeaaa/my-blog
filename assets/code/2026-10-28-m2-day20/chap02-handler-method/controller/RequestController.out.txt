[index.html의 버튼 네 개로 각 화면 열기]
실행 환경: Spring Boot 4.1.2 내장 Tomcat, http://localhost:8080
요청은 브라우저 대신 스크립트로 보냈다. > 는 보낸 요청, < 는 받은 응답이다. HTML 본문은 <body> 안쪽만(주석 제외) 옮겼다.
