이 파일의 구성
  1) 수업 파일 03_Async 의 html 4개를 헤드리스 Chrome 에서 열어 본 콘솔 출력
     - 각 줄 왼쪽의 [ 1.0초] 는 페이지를 연 뒤(또는 버튼을 누른 뒤) 지난 시간이다. 0.1초 단위로 반올림했고 실행할 때마다 조금 달라진다.
     - 버튼은 click() 으로 눌렀다. 실제 마우스 입력은 아니다.
     - 객체·Promise·Error 는 한 줄 글자로 바꿔서 기록했다(Chrome 콘솔에서 펼쳐 볼 수 있는 모양과는 다르다).
       (Error 는 이름과 메시지만 남겼다. 실제 콘솔에는 스택이 함께 나온다.)
     - 04_fetch 는 외부 서버(jsonplaceholder.typicode.com)에 실제로 요청을 보냈다. 응답 내용은 서버 사정에 따라 달라질 수 있다.
  2) "수업 코드가 아니라" 로 시작하는 부분: 수업 파일의 주석을 풀어 만든 동기 처리 변형, 그리고 본문 설명을 확인하려고 만든 짧은 예시 코드와 결과
실행 환경: Chrome(headless)

----- 수업 코드가 아니라 예시 코드: 실행 순서 확인
hi / setTimeout(HI,3000) / bye / setTimeout(Bye,3000) 순서로 쓴 코드의 실행 순서: ["안녕하세요","안녕히가세요","(스크립트 끝)","HI","Bye"]
setTimeout(..., 0) 은 지금 하던 일 뒤에: ["동기 코드 A","동기 코드 B (200ms 점유한 뒤)","timeout 0"]
Promise.then 과 setTimeout(0) 의 순서: ["동기 코드","Promise.then (마이크로태스크)","setTimeout 0 (태스크)"]
