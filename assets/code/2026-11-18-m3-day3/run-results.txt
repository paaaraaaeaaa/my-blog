==================== 수업 코드가 아니라 본문 설명을 확인하려고 만든 예시 코드 (Chrome) ====================
----- 폼 요소: 체크박스는 value 가 아니라 checked 로 읽는다
체크 전 value / checked: ["on",false]
click() 뒤 value / checked: ["on",true]

----- 폼 안 버튼의 type 기본값과 제출
type 을 안 쓴 버튼의 type: submit
type="button" 버튼의 type: button
type 없는 버튼을 한 번 눌렀을 때 submit 이벤트 횟수: 1
type="button" 버튼을 한 번 눌렀을 때 submit 이벤트 횟수(횟수를 0 으로 되돌린 뒤): 0

----- focus 는 버블링되지 않고 focusin 은 버블링된다
입력 칸에 focus() 했을 때 form 에 등록한 핸들러가 호출된 횟수: {"focus":0,"focusin":1}

----- target 과 currentTarget
안쪽 버튼을 눌렀을 때, 바깥 div 를 눌렀을 때 (target / currentTarget): ["BUTTON / DIV","DIV / DIV"]
일반 함수와 화살표 함수로 등록해도 e.currentTarget 은 등록한 요소인가: {"일반함수":true,"화살표함수":true}

----- once 옵션과 프로퍼티 핸들러 제거
once: true 로 등록하고 두 번 누르면 실행된 횟수: 1
onclick 프로퍼티로 등록한 핸들러: 단계마다 클릭하고 실행된 횟수: {"등록 뒤 클릭 1번":1,"removeEventListener 뒤 클릭 1번 더":2,"onclick = null 뒤 클릭 1번 더":2}
onclick 프로퍼티와 addEventListener 를 섞으면(둘 다 실행): ["listener 1","property","listener 2"]

----- keydown 의 key 와 code
Shift + A 를 눌렀을 때를 흉내 낸 이벤트: {"key":"A","code":"KeyA","shift":true}
