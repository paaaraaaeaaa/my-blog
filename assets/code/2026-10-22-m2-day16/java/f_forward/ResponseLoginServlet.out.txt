[forward.html 로그인 폼 제출 (/forward → /print 위임)]

--- forward.html에서 아이디 user01, 비밀번호 pass01로 로그인 ---
> POST /forward
> Content-Type: application/x-www-form-urlencoded
>
> userId=user01&password=pass01

< HTTP/1.1 200
< Content-Type: text/html;charset=UTF-8
< Transfer-Encoding: chunked

<!doctype html>
<html>
<head>
</head>
<body>
<h3 align="center">user01님 환영합니다.</h3></body>
</html>
