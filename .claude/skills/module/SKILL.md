# 모듈 전환 정리

## 순서

1. 물어본다 — "모듈을 시작하는 거예요, 끝내는 거예요? 몇 번 모듈이에요?"
2. **시작할 때**
   - `_data/modules.yml`의 이름이 실제 모듈 이름과 같은지 확인하고, 다르면 고칠지 묻는다.
   - `_data/module_schedule.yml`에 `"N": { start: "YYYY-MM-DD", end: "YYYY-MM-DD" }`를 추가한다. 종료일을 모르면 묻고, 모르면 비워 둔다(막대가 빗금으로 표시됨).
   - `_data/now.yml`의 `status`를 이번 모듈에서 하는 일로 바꾼다. 홈 미션 패널 🔥 문구가 된다. (15자 안팎, 예: `"백엔드 API 설계 기록 중"`)
3. **끝낼 때**
   - 이 모듈 결과물 글이 `_posts/Projects/`에 있는지 확인한다. 없으면 "`/project`로 결과물 회고를 쓸까요?"라고 묻는다.
   - `_data/now.yml`의 `status`를 "모듈 N 회고 정리 중"처럼 바꿀지 묻는다.
4. 바뀐 파일의 diff만 보여준다. 내가 좋다고 하기 전에는 커밋하지 마.
5. 내가 확인하면 커밋하고 push 한다. 커밋 메시지: `module: 모듈 N 시작` 또는 `module: 모듈 N 종료`
